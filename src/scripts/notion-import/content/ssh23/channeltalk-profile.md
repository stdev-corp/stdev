참가자분들이 팀 매칭 과정에서 서로가 속한 팀과 역할에 대해서 궁금해질 것을 고려하여 채널톡 프로필 이름을 이용하기로 하였습니다. 아래 규칙에 따라 채널톡 프로필 이름을 변경해주시면 참가자 분들이 팀을 이뤄나가는 과정에서 큰 도움이 될 것이라고 생각합니다.

&nbsp;

:::callout{icon="📢" color="gray_background"}
\[`팀 번호` `팀원 번호`-`역할군`\] `이름`\
예시) \[A1-BP\] 오승빈, \[PD\] 황제욱
:::

## 규칙 설명

### 1. 역할군

지원하신 역할군에 따라 B, P, D 중 하나 이상을 BPD 순서대로 붙이시면 됩니다.

뜻은 Business, Programming, Design입니다.

### 2. 팀 번호 / 팀원 번호

아직 **팀리더 분이 속하시지 않으셨다면** 팀 번호와 팀원 번호는 빈 칸으로 두시면 됩니다.

만약 **팀리더 분이 속하셨다면** 팀리더께 부여된 팀번호를 사용해주시면 됩니다.

팀원 번호의 경우 팀 리더가 1번, 팀원이 자율적으로 이어진 숫자를 사용하시면 됩니다.

:::callout{icon="🔒" color="gray_background"}
참가자 개인정보 보호를 위해 이 부분의 명단은 삭제했습니다.
:::

## 적용

따라서 다음과 같이 정리됩니다.

리더가 속한 팀 : \[`팀 번호` `팀원 번호`-`역할군`\] `이름`

리더가 속하지 않은 팀 : \[`역할군`\] `이름`
