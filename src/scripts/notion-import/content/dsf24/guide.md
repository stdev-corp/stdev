2. **디스코드 사용 관련 안내사항**

이번 행사에서는 운영진 및 참가자 간의 소통을 위해 디스코드를 사용할 예정입니다.

아래 링크로 접속해주시면 감사하겠습니다.

[https://discord.gg/HEZcrkYe](<https://discord.gg/HEZcrkYe>)

\[SPARCS 과학 해커톤 2024\] 서버에는 총 4개의 채널이 존재합니다.

**000 - 공지방** : 운영진이 공지사항을 올리기 위해 사용하는 채널입니다. 이 채널에서는 참가자가 채팅을 올리는 것이 불가능합니다.

**001 - 단체방** : 모든 운영진과 참가자가 자유롭게 소통할 수 있는 채널입니다.

**팀빌딩** : 개인 참가자들의 자유 팀빌딩을 위해 사용되는 채널입니다.

**팀빌딩 - 공지** : 개인 참가자들 팀빌딩 관련 공지가 올라오는 채널입니다. 이 채널에서는 참가자가 채팅을 올리는 것이 불가능합니다.

**티켓 오픈** : 문의사항을 받는 채널입니다. 모든 문의사항은 티켓 봇을 통해 전달하면 운영진들이 빠르게 답변드리겠습니다 :)

3. **티켓봇 사용법**

1\) \[티켓 오픈\] 채널에서 원하는 카테고리를 선택합니다.

:::table{header-row="false" header-column="true" widths="117,580"}
| 장소 | 장소(위치, 시설 등)와 관련된 문의사항입니다. |
| --- | --- |
| 발표 | 2차 심사 관련 문의사항입니다. |
| 숙소 | 호텔와 관련된 문의사항입니다. |
| 부스 | 1차 심사 관련 문의사항입니다. |
| 기술 지원 | 인터넷, 전기 등 기술적 지원 관련 문의사항입니다. |
| 식사 | 식사 및 간식 관련 문의사항입니다. |
| 팀빌딩 | 개인 참가자 사전 팀빌딩 관련 문의사항입니다. |
| 기타 | 위의 항목에 해당하지 않는 기타 문의사항입니다. |
:::

2\) 카테고리를 선택하면 자동으로 티켓 채널이 만들어집니다. 해당 채널은 매칭된 운영진과 질문자만 볼 수 있는 비공개 채널입니다.

3\) 질문이 종료되면, \[종료\]를 누른 후 \[수락\]을 눌러 채널을 종료해주세요!

4\) 티켓을 강제로 닫고 싶을때에는 `/force-close` 를 사용하면은 강제로 닫을 수 있습니다.

4. **개인 참가자 팀빌딩 안내**

개인 참가자 자유 팀빌딩은 **10/16 (수) \~ 10/17 (목)** 동안 진행됩니다!
:::
