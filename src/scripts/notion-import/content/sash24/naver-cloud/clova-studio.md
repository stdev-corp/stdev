NAVER CLOVA Studio는 HyperCLOVA LLM을 활용하여 사용자의 질문에 맞는 답을 하거나, 대량의 데이터셋을 HyperCLOVA X 언어 모델과 결합해 AI 기반의 특화된 서비스를 손쉽게 만들 수 있는 개발 도구입니다.

https://www.ncloud.com/product/aiService/clovaStudio

&nbsp;

CLOVA Studio에서 제공하는 기능은 다음과 같습니다.

- 문장 생성 : 입력된 키워드를 활용한 마케팅 문구, 자기소개서 생성, 보고서, 이메일 작성 기능을 제공합니다.
- 문장 변환 : 입력된 문장을 다양한 톤과 스타일로 변환하는 기능을 제공합니다. ( 사투리, 문체 변환 등 )
- 대화 : 고유의 페르소나를 가진 AI를 생성하여, 원하는 형태로 제공 가능
- 분류 : 문장의 유형, 감정, 의도 등 분류 기능 제공
- 요약 : 긴 문장에서 핵심 키워드, 내용을 기반으로 짧은 문장으로 요약하는 기능 제공

&nbsp;

CLOVA Studio는 기본적으로 AI Filter 기능을 제공하고 있습니다. ( API Call 시 비활성화 가능 )

부적절한 단어, 욕설 등은 자동으로 인식하여 API 응답 부분에 함께 제공하고 있습니다.
