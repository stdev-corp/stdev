CLOVA Studio는 API에서 LLM을 호출할 수 있도록 기능을 제공하고 있습니다.

&nbsp;

API를 활용하기 위해서는 우선 테스트앱을 생성하여 API 키를 발급받아야 합니다.

&nbsp;

1. 플레이그라운드에서 테스트 앱으로 생성할 작업을 입력해주세요. ( 튜닝 등으로 학습한 모델을 사용할 예정이라면, 해당 모델을 선택해주세요. )

::image{src="notion-asset:a0058" alt="API 활용하기"}

2. 위 화면에서 저장 버튼을 클릭해주세요

3. **\[테스트 앱\]** 버튼을 클릭해 주십시오.

4. 테스트 앱 이름을 입력한 후 **\[생성\]** 버튼을 클릭해 주십시오.

   - 테스트 앱이 생성되며, 테스트 앱 팝업 창이 나타납니다.


   - 테스트 앱의 API 정보를 확인할 수 있으며, AI Filter 사용 여부를 설정할 수 있습니다.(API에 관한 자세한 내용은 [CLOVA Studio API 가이드](<https://api.ncloud-docs.com/docs/ai-naver-clovastudio-summary>) 참조)
   - 코드 타입은 **curl**과 **python**이 제공됩니다.

   ::image{src="notion-asset:a0061" alt="API 활용하기" width=704}

   - **\[복사\]** 버튼을 클릭하여 API 정보를 클립보드에 복사할 수 있습니다.
   - **\[재발급\]** 버튼을 클릭하여 API Gateway Key를 재발급할 수 있습니다.
   - **가이드 보기**를 클릭하면 [AI Filter 가이드](<https://guide.ncloud-docs.com/docs/clovastudio-playground01#AIFilter>)를 확인할 수 있습니다.
